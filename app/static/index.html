Connect a calendar

Paste your calendar's secret iCal address. Notetaker reads it every few minutes and sends the bot to calls that have a link. It's read-only, and you can reset the address in your calendar any time.

Where to find it
Google Calendar
Settings (⚙) → click your calendar on the left → Integrate calendar → Secret address in iCal format.
Outlook / Microsoft 365
Settings → Calendar → Shared calendars → Publish a calendar → “Can view all details” → Publish → copy the ICS link.
Yandex Calendar
The calendar's ⋯ → Settings → Export → copy the link.
Zoho Calendar
Settings → My calendars → the calendar → Export → private iCal address.
Apple iCloud
Calendar → share icon → Public Calendar → copy the link (webcal://…).
